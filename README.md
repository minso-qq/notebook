 Записная книжка (Console Notes App)

Консольное приложение на Python для работы с заметками.  
Позволяет создавать, просматривать и удалять записи, а также выводит статистику действий пользователя при завершении программы.

---

##  Возможности

-  Просмотр всех заметок
-  Добавление новой заметки
-  Удаление заметки по номеру
-  Подсчёт действий пользователя:
  - количество просмотров записей
  - количество добавленных записей
  - количество удалённых записей
-  Текстовое меню в консоли

---

##  Технологии

- Python 3.x
- Стандартная библиотека Python  
(без сторонних зависимостей)

---

##  Запуск программы

1. Убедитесь, что установлен Python версии 3.x
2. Сохраните файл с кодом, например:

      notes.py
   

3. Запустите программу:

      python notes.py
   

---

##  Использование

После запуска программы отображается меню:

_______________________________________
| Добро пожаловать в Записную книжку! |
| Что бы вы хотели сделать?           |
| 1. Посмотреть имеющиеся записи      |
| 2. Добавить запись                  |
| 3. Удалить запись                   |
| 4. Завершение программы             |
|_____________________________________|

Введите номер команды

---

##  Команды меню

| Команда | Описание                  |
| 1       | Просмотр всех записей     |
| 2       | Добавление новой записи   |
| 3       | Удаление записи по номеру |
| 4       | Выход из программы        |

---

##  Особенности работы

- Нумерация записей начинается с 1
- Если записей нет, выводится сообщение об отсутствии данных
- Все заметки хранятся только во время работы программы
- После выхода из программы все данные удаляются

---

##  Пример итоговой статистики

Результаты:

Было добавлено - 2
Было удалено записей - 1

##  Ограничения

- Нет сохранения заметок в файл
- Нет обработки ошибок ввода
- Возможны ошибки при вводе некорректного номера записи
